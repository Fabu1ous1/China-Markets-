# 🛍 Telegram Shop Bot

Telegram-бот магазина: каталог с фото/видео, выбор вкусов, корзина, оформление заказа
и мгновенные уведомления админу. Всё управление — прямо в Telegram, без кода.

## Возможности

**Покупатель**
- 🔞 Проверка возраста при первом входе (`MIN_AGE`)
- 🛍 Каталог: категории → товары → карточка с фото/видео (альбом до 10 файлов) и описанием
- 🍬 Выбор вкуса (закончившиеся помечены ❌), выбор количества ➖/➕
- 🛒 Корзина с подсчётом суммы, удаление позиций
- 📝 Оформление в 6 шагов: имя, телефон (кнопка «отправить номер»), адрес, доставка, оплата, комментарий.
  Данные прошлого заказа подставляются кнопкой
- 📦 «Мои заказы» со статусами + уведомления при смене статуса

**Админ** (`/admin` или кнопка «⚙️ Админка»)
- 🔔 Новый заказ сразу приходит всем админам: контакты, адрес, товары, вкусы, количество, **итог**
  и кнопки «Принят / Отправлен / Доставлен / Отменён» — клиент получает уведомление автоматически
- ➕ Добавление товара пошагово: категория → название → описание → цена → фото/видео → вкусы
- ✏️ Редактирование названия, описания, цены, замена медиа, добавление вкусов
- 🍬 Наличие вкусов одним нажатием (✅/❌), скрытие товара из каталога
- 📊 Статистика: заказы и выручка за 24ч / 7 / 30 дней / всё время, топ продаж
- 📣 Рассылка всем покупателям (текст, фото, видео)

## Запуск за 10 минут

1. Создайте бота у [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Установите Python 3.10+ и зависимости:
   ```bash
   cd telegram-shop-bot
   python3 -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   cp .env.example .env            # и заполните BOT_TOKEN, ADMIN_IDS
   python bot.py
   ```
4. Напишите боту `/start`, затем `/admin` → «📂 Категории» → создайте категорию → «➕ Добавить товар».

> Каждый админ должен хотя бы раз нажать `/start` у бота — иначе Telegram не даст отправить ему уведомление.

## Настройки (`.env`)

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `ADMIN_IDS` | ID админов через запятую — им приходят заказы |
| `SHOP_NAME`, `CURRENCY` | название магазина и валюта |
| `MIN_AGE` | минимальный возраст покупателя (0 — без проверки) |
| `TZ_OFFSET_HOURS` | часовой пояс для времени заказов |
| `DELIVERY_METHODS`, `PAYMENT_METHODS` | варианты через запятую |
| `CONTACTS` | текст раздела «Контакты» (`\n` — перенос строки) |

## Работа 24/7 на сервере (VPS, Ubuntu)

```ini
# /etc/systemd/system/shopbot.service
[Unit]
Description=Telegram shop bot
After=network.target

[Service]
WorkingDirectory=/opt/telegram-shop-bot
ExecStart=/opt/telegram-shop-bot/venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl enable --now shopbot
sudo journalctl -u shopbot -f   # логи
```

Все данные — в одном файле `shop.db` (SQLite). Бэкап = копия этого файла.
