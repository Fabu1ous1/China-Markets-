# 🛍 Telegram Shop Bot

Telegram-бот магазина: каталог с фото/видео, выбор вкусов, корзина, оформление заказа
и мгновенные уведомления админу. Всё управление — прямо в Telegram, без кода.

## Возможности

**Покупатель**
- 🔞 Проверка возраста при первом входе (`MIN_AGE`)
- 🛍 Каталог: категории → товары → карточка с фото/видео (альбом до 10 файлов) и описанием
- 🍬 Выбор вкуса, выбор количества ➖/➕ — цена за штуку пересчитывается на лету
- 📉 **Оптовая шкала**: чем больше штук одной модели, тем дешевле каждая (вкусы можно миксовать).
  Бот подсказывает: «возьмите ещё 3 шт. — будет по 13 $»
- 🎟 **Промокоды** в корзине (процент или фиксированная сумма)
- 🔔 **«Сообщить о поступлении»** — на закончившийся вкус можно подписаться, бот напишет, когда он вернётся
- ⭐ **Отзывы**: после доставки бот просит оценить товары; рейтинг и отзывы видны в карточке
- 🛒 Корзина с подсчётом суммы, оптовой скидки и промокода
- 📝 Оформление в 6 шагов: имя, телефон (кнопка «отправить номер»), адрес, доставка, оплата, комментарий.
  Данные прошлого заказа подставляются кнопкой
- 📦 «Мои заказы» со статусами + уведомления при смене статуса

- 💬 **Режим «Цена по запросу»** (`HIDE_PRICES=1` или цена «-» у отдельного товара): клиент
  собирает корзину и отправляет заявку → админ жмёт «💲 Назначить цену» → клиент подтверждает
  одной кнопкой → заказ уходит в работу
- 🗺 Шаг «Штат/регион» с блокировкой регионов, куда доставка запрещена (`REGIONS`, `BLOCKED_REGIONS`)

**Админ** (`/admin` или кнопка «⚙️ Админка»)
- 🔔 Новый заказ сразу приходит всем админам: контакты, адрес, товары, вкусы, количество, **итог**
  и кнопки «Принят / Отправлен / Доставлен / Отменён» — клиент получает уведомление автоматически
- ➕ Добавление товара пошагово: категория → название → описание → цена → оптовые цены → фото/видео → вкусы
- 📉 Оптовые цены задаются строками `5 14`, `10 13`, `20 12` (от 5 шт. по 14 и т.д.)
- 🎟 Промокоды: `WELCOME10 10%` или `SALE5 5 100` (5 единиц скидки, лимит 100 использований);
  каждый покупатель использует код один раз, включение/выключение одной кнопкой
- ⭐ Уведомление о каждом новом отзыве + удаление неподходящих
- 🔔 Когда включаете вкус обратно (❌→✅), все ждавшие покупатели получают уведомление автоматически
- ✏️ Редактирование названия, описания, цены, замена медиа, добавление вкусов
- 🍬 Наличие вкусов одним нажатием (✅/❌), скрытие товара из каталога
- 📊 Статистика: заказы и выручка за 24ч / 7 / 30 дней / всё время, топ продаж
- 📣 Рассылка всем покупателям (текст, фото, видео)

## Запуск за 10 минут

1. Создайте бота у [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Установите Python 3.10+ и зависимости:
   ```bash
   cd telegram-shop-bot
   python3 -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   cp .env.example .env            # и заполните BOT_TOKEN, ADMIN_IDS
   python bot.py
   ```
4. Напишите боту `/start`, затем `/admin` → «📂 Категории» → создайте категорию → «➕ Добавить товар».

> Каждый админ должен хотя бы раз нажать `/start` у бота — иначе Telegram не даст отправить ему уведомление.

## Настройки (`.env`)

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `ADMIN_IDS` | ID админов через запятую — им приходят заказы |
| `SHOP_NAME`, `CURRENCY` | название магазина и валюта |
| `MIN_AGE` | минимальный возраст покупателя (0 — без проверки) |
| `TZ_OFFSET_HOURS` | часовой пояс для времени заказов |
| `DELIVERY_METHODS`, `PAYMENT_METHODS` | варианты через запятую |
| `CONTACTS` | текст раздела «Контакты» (`\n` — перенос строки) |

## Работа 24/7 на сервере (VPS, Ubuntu)

```ini
# /etc/systemd/system/shopbot.service
[Unit]
Description=Telegram shop bot
After=network.target

[Service]
WorkingDirectory=/opt/telegram-shop-bot
ExecStart=/opt/telegram-shop-bot/venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl enable --now shopbot
sudo journalctl -u shopbot -f   # логи
```

Все данные — в одном файле `shop.db` (SQLite). Бэкап = копия этого файла.

## 🇺🇸 США

Готовый пример настроек — `.env.us.example` (21+, штаты, скрытые цены, UPS/FedEx).
Бот закрывает часть требований, но **онлайн-продажа вейпов в США жёстко регулируется** — до запуска:

1. **PACT Act** (федеральный закон, распространяется на вейпы с 2021 г.):
   - регистрация продавца в **ATF** и в налоговых органах каждого штата, куда продаёте;
   - **проверка возраста через коммерческую базу данных** при покупке (сервисы вроде AgeChecker,
     Veratad, IDology) — галочка «мне 21+» в боте этого НЕ заменяет;
   - доставка только с **проверкой ID и подписью взрослого** при получении;
   - **USPS вейпы не возит** — только UPS/FedEx/DHL по их программам для табачной продукции;
   - уплата акцизов и налогов штата, ежемесячная отчётность.
2. **FDA**: легально продавать можно только продукты с разрешением FDA (PMTA). Большинство
   ароматизированных одноразок без разрешения — их изымают на таможне, продавцов штрафуют.
   Уточните у завода, у каких моделей есть PMTA/marketing order.
3. **Законы штатов**: запреты вкусов, запрет доставки покупателю, лицензии. Ведите актуальный
   список в `BLOCKED_REGIONS`.

Рекомендую 1 консультацию с юристом по табачному регулированию США перед первой продажей —
это дешевле любого штрафа.
